# Stock Price Prediction Using LSTM

[![Python 3.11 | 3.12](https://img.shields.io/badge/python-3.11%20%7C%203.12-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.40+-FF4B4B.svg)](https://streamlit.io/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.110+-009688.svg)](https://fastapi.tiangolo.com/)

An educational and research time-series forecasting system that downloads genuine historical daily market data for Indian NSE and US equities, trains an LSTM recurrent neural network, evaluates performance on unseen chronological holdout data, benchmarks against a naive persistence baseline, and serves results through an interactive Streamlit dashboard, a FastAPI REST service, and an executed Jupyter research notebook.

> **Important Disclaimer:** This application is built strictly for education, software engineering demonstration, and time-series research. Financial markets are highly volatile and non-stationary. Predictions generated by this system are mathematical point forecasts and must not be used as financial, investment, or trading advice. No synthetic or mock market data is ever generated.

---

## Key Features

- **Genuine Market Data:** Connects directly to Yahoo Finance via `yfinance` to ingest daily OHLCV history for Indian NSE stocks (`RELIANCE.NS`, `TCS.NS`, `INFY.NS`, `HDFCBANK.NS`, `SBIN.NS`) and US equities (`AAPL`, `MSFT`, `NVDA`, `AMZN`, `TSLA`).
- **Data Leakage Prevention:** Feature scaling (`RobustMinMaxScaler`) is derived strictly from historical training observations and never fitted across the entire dataset.
- **Strict Chronological Splitting:** Observations are split sequentially (default: 80% train / 20% test) with a chronological validation tail. No sequence shuffling is performed.
- **Deep LSTM Sequence Modeling:** Configurable sliding lookback windows (default: 60 sessions) map prior closes to the strictly following closing price.
- **Dual Engine Architecture:** Retains full TensorFlow/Keras LSTM implementation while integrating a native-dependency-free Pure NumPy analytical LSTM engine for reliable execution across environments with Windows Smart App Control or container constraints.
- **Persistence Baseline Benchmark:** Benchmarks holdout predictions against a naive last-close persistence baseline across MAE, RMSE, and MAPE. Reports underperformance honestly.
- **Responsive Multi-Viewport Dashboard:** Streamlit interface visually verified across mobile (320px, 375px, 390px, 430px), tablet (768px), and desktop (1024px, 1440px) screen viewports.
- **RESTful API Backend (Option B):** FastAPI service (`api.py`) exposing `/health`, `/tickers`, and `/predict` endpoints for distributed cloud deployments (e.g., Render backend + Vercel/Netlify frontend).
- **Executable Jupyter Notebook:** Fully executed research notebook (`notebooks/Stock_Price_Prediction_LSTM.ipynb`) with real outputs and downloadable prediction CSVs.

## Windows 11 Setup & Installation Guide

### Prerequisites
- **Operating System:** Windows 11 (64-bit) or Linux/macOS.
- **Python Version:** 64-bit **Python 3.11** or **Python 3.12** installed from [python.org](https://www.python.org/downloads/). Ensure "Add python.exe to PATH" is checked during installation.

### 1. Extract and Navigate to Project
Extract the archive and open PowerShell inside the project directory:

```powershell
cd "c:\Users\Project\Stock Price"
```

### 2. Create and Activate Virtual Environment
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

*Note: If PowerShell displays an execution policy error, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` and reactivate.*

### 3. Install Dependencies
For the Streamlit dashboard:
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

For development, testing (pytest), research notebook (Jupyter), and FastAPI:
```powershell
pip install -r requirements-dev.txt
```

## Running the Application

### Option A: Interactive Streamlit Dashboard (Primary)
To launch the responsive web dashboard:
```powershell
python -m streamlit run app.py
```
Or double-click `run_dashboard.bat`. Open your browser at `http://localhost:8501`.

### Option B: FastAPI Backend Server
To start the REST API server:
```powershell
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```
Or double-click `run_api.bat`. The interactive Swagger API documentation will be available at `http://localhost:8000/docs`.

### Running the Research Notebook
Launch Jupyter Lab:
```powershell
python -m jupyter lab
```
Or double-click `run_notebook.bat`. Open `notebooks/Stock_Price_Prediction_LSTM.ipynb` and run all cells.

## Running Automated Tests

By default, running `pytest` executes the full **offline verification suite** (35 deterministic unit, gradient, validation, and API tests, completely independent of the internet):
```powershell
python -m pytest -v
```

All 35 offline tests execute in ~1 second and verify sequence slicing, chronological splitting, ticker validation, metric calculations, edge cases, data leak prevention, mock downloads, missing dependency handling, numerical gradient checks ($\text{rel\_err} < 2\times 10^{-5}$), early stopping weight restoration, FastAPI endpoint validation, rate limiting, and concurrency control.

To execute the live Yahoo Finance integration test (requires active internet access):
```powershell
python -m pytest -m "integration" -v
```

To run all 36 tests (offline unit tests + live market data integration):
```powershell
python -m pytest -m "" -v
```

## Streamlit Community Cloud Deployment Guide (Option A)

This project is fully structured and verified for **Streamlit Community Cloud**:

### 1. Repository Preparation
Ensure your repository on GitHub contains:
- `app.py` in the root directory (primary entrypoint).
- `requirements.txt` in the root directory (installs lightweight, Linux-compatible packages without binary conflicts).
- `src/stock_forecaster.py` containing the forecasting engine.

### 2. Deployment Steps
1. Navigate to [share.streamlit.io](https://share.streamlit.io/) and log in with GitHub.
2. Click **New app**.
3. Select your repository and branch (`main`).
4. Set **Main file path** to `app.py`.
5. Under **Advanced settings**, ensure Python 3.11 or 3.12 is selected. No environment secrets or API keys are required.
6. Click **Deploy!**

The application will start, install dependencies via `pip`, and serve the responsive dashboard at your unique `*.streamlit.app` URL.
